# rain-alert

长江雨课堂随堂题目提醒工具：电脑保持学生课堂网页打开，识别新题后通过 Server酱³ 提醒安卓手机，收到提醒后由本人手动作答。

> 当前为最小验证版，非雨课堂官方产品。电脑仅联网还不够：需要保持程序、工具独立打开的 Edge 和具体学生课堂页面运行。

## 下载使用

**不懂编程的使用者，优先下载[简明转发包](downloads/rain-alert-starter.zip)**（打开文件页后点击下载按钮）。解压后包含程序压缩包和一页使用步骤；继续将内部程序包“全部解压”后操作。

- [一页使用步骤 PDF](docs/quickstart.pdf)
- 也可点击仓库右上方 **Code → Download ZIP**，解压源码，进入包含 `setup.cmd` 的目录。

分享包与本仓库源码的监测功能一致；分享包中不含原使用者的账号会话、手机推送密钥或运行记录。

## 运行条件

- Windows 11，Intel/AMD 64位；Python 3.13 完整版（含启动器和 Tcl/Tk）。
- Microsoft Edge；可持续联网、供电、避免休眠的电脑。
- 安卓手机，以及本人自己的 Server酱³ 账号和 SendKey。
- 本人有权进入的长江雨课堂学生账号；每次只监测一门当前课堂。

官方入口：[Python](https://www.python.org/downloads/windows/) · [Edge](https://www.microsoft.com/edge/download) · [Server酱³ App](https://sc3.ft07.com/client) · [Server酱³ 官网](https://sc3.ft07.com/) · [长江雨课堂](https://changjiang.yuketang.cn/web/)

## 首次设置

在 **Windows 文件资源管理器** 中双击脚本，不是在代码预览里打开。不要直接在 ZIP 内运行。

1. 安装 Python 3.13 和 Edge，解压本项目。
2. 双击 `setup.cmd`，等显示 **Setup complete**。
3. 手机安装 Server酱³，在官网注册/登录，取得以 `sctp` 开头的 SendKey，用同一密钥登录手机 App 并允许通知。Server酱Turbo 的 `SCT` 密钥不适用。
4. 双击 `configure-sc3.cmd`，在本地窗口保存自己的 SendKey。
5. 双击 `test-notification.cmd`，确认手机实际收到弹窗或振动，再做锁屏测试。服务器接收成功不代表手机收到。

通知服务的额度、试用与费用以本人当前账号页面为准。

## 每次上课

1. 双击 `monitor.cmd`。
2. 在工具新开的独立 Edge 中登录学生账号，进入具体正在上课的课堂，看到老师 PPT 与课堂动态；不要只停在课程列表。
3. 点击对应黑色窗口的标题栏，按回车，等待5秒；确认出现 `armed` 与 `monitor_classroom_scope_bound`。
4. 保持电脑、浏览器、课堂页和黑色窗口运行，手机收到提醒后自行进入雨课堂作答。
5. 结束时按 **Ctrl+C**。换课时停止并重新启动，不会自动跟随课表换课。

初次使用，先让有权限的配合者在测试课堂真实发送一道随堂题，确认自己的电脑和手机组合可用。测试需要老师发布和另一个学生账号进入；单纯切换到 PPT 题目页不等于发布题目。

## 排错

- `check-install.cmd`：检查 Python、依赖、Edge 常见安装路径和配置文件是否存在；不会显示密钥或发送通知。
- 只有 `heartbeat`：仅证明本地程序在运行；还需确认课堂范围已绑定。
- 显示代码而没有黑色窗口：在文件资源管理器中找到实际解压文件，双击 Windows 命令脚本。
- 手机收不到：先运行独立通知测试，检查网络、通知权限、账号额度和手机是否使用同一 SendKey。
- 页面/连接关闭、离线或疑似授权失败：人工检查课堂与登录状态，再重新启动；断线期间题目不保证补回。

## 实现和文件

保留现有轻量结构：Python 标准库、SQLite 本地去重、Playwright 观察官方网页正常收到的消息、Server酱³ 通知。没有云端代管用户账号。

- `rain_probe.py`：课堂消息观察、固定课堂范围、发布识别、去重和通知。
- `monitor.cmd`：自动提醒验证入口。
- `probe.cmd`：仅采集消息结构的开发排查入口，不发新题提醒。
- `sc3_setup.py` / `configure-sc3.cmd`：本机密钥配置窗口。
- `test_probe.py`：合成协议和模拟发送检查。
- `adapter.example.json`：早期通用 `watch` 骨架模板；日常 `monitor` 不需要填写。

## 验证情况和限制

2026年10月的授权课堂测试记录：实际捕获随堂单题发布，自动手机提醒实收两次，其中一次用户目测约4秒；18项模拟检查通过。用户后续报告连续使用约两周体验良好，这是个人使用反馈，不是多设备或长期稳定性统计。

本次上传会重新运行模拟测试，没有重新开展真实课堂测试。不得将模拟通过、通知服务器回执或历史结果作为当前所有课堂都可用的保证。

尚未完整验证：长期锁屏、其他题型、静默连接失效、登录失效业务码、断线补题和准确课堂结束识别；没有自动重新登录、自动换课或每次10秒内送达的保证。监测依赖网页实际消息，平台变化可能需要适配。协议参考时间与不同设备时钟也可能存在偏差。

## 本地数据与安全

登录会话、推送密钥和运行数据在 `local/`，已加入 Git 忽略规则。不要上传 `local/`、`.venv/`、数据库、消息日志、真实 `adapter.json` 或 `.env`。每位使用者独立配置自己的凭据；报告问题时先脱敏。

本工具不自动答题、签到或刷新。本人进入课堂可能被平台正常记为在线/进入记录。通知仅发送通用提醒和事件摘要，不发送题干、答案或雨课堂登录凭据。仅用于本人有权访问的课堂。
